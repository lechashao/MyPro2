# 鲍勃的世界 · Bob's World

一个本地、单用户的人生情景实验室。以鲍勃为主角，导入健康与工作助手的记忆，探索不同选择下的七天生活分支。

## 启动

需要 Python 3.11+、Node.js 20+。在仓库根目录运行：

```sh
python -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
npm ci
npm run build
.venv/bin/python -m uvicorn backend.app:app --host 127.0.0.1 --port 8000
```

浏览器打开本机 8000 端口。当前云实例已安装依赖并构建前端，也可直接使用 `npm start`。React 前端随 FastAPI 一起提供，运行时没有 CDN 或外部模型依赖。修改 `web/app.jsx` 后执行 `npm run build`，刷新浏览器。API 文档位于 `/docs`。

## 已实现

- 中文响应式界面：世界概览、记忆档案、平行人生和实验记录。
- 档案编辑；虚构示例记忆与真实导入记录分开。
- JSON 上传或粘贴导入、输入校验、重复记录过滤、删除记忆。
- 健康顾问与工作顾问的规则建议，显示来源记忆作为背景。
- 手动选择每日行动，或按平衡、事业、休息三种策略自主推进。
- “全自动模拟七天”：无需逐日操作，鲍勃评估工作、作息/精力及自由时间后自主选择；保存候选评分、理由和完成摘要。
- 同种子外部事件、七天时间分配、项目进度、游戏精力、作息目标统计。
- 从任意已发生的日期分岔，保留此前历史与档案快照。
- 三策略批量对比、进度曲线、JSON 导出、分支删除。
- SQLite 本地持久化。默认路径 `.data/bob.sqlite3`，可通过 `BOB_DB_PATH` 修改。

## 记忆导入格式

```json
{
  "memories": [
    {
      "source": "health_assistant",
      "type": "goal",
      "content": "希望每周安排三次散步。",
      "observed_at": "2026-11-03T09:00:00+03:00",
      "confidence": 1
    },
    {
      "source": "work_assistant",
      "type": "reported_fact",
      "content": "正在负责一个新项目。",
      "observed_at": "2026-11-03T09:00:00+03:00",
      "confidence": 0.9
    }
  ]
}
```

`source` 仅支持 `health_assistant`、`work_assistant`；`type` 支持 `reported_fact`、`preference`、`goal`、`hypothesis`。支持 ISO 日期时间；未标时区按 UTC 处理，日期显示使用 Europe/Istanbul。可信度范围 0–1。一次最多 200 条、1 MB；每条正文最多 2000 字符；本地库最多 2000 条。相同来源、正文、时间、类型、可信度的记录会去重。

创建分支时选择虚构示例或已导入记忆。记忆作为可追溯背景展示，不解析聊天文本为医学结论或自动数值参数。作息目标由用户在档案中显式配置。导入和编辑档案仅影响新建分支；从旧分支分岔会保留旧快照。

没有自动读取其他助手、调用云模型或上传数据。删除记忆会移除主记忆库、所有分支快照及事件引用中的该条记录；不删除其已经产生的日程。之前导出的文件需自行管理。

## 模拟规则与边界

### 全自动模式

点击“全自动模拟七天”即可新建独立路径并运行至第七天，已有分支保持不变。优先使用已导入记忆；没有导入时使用明确标记的虚构示例。顾问仍是本地规则角色，没有调用云端 LLM。记忆文本用作背景，明确的作息目标来自人物档案。

接口 `POST /api/simulations/auto`，JSON 可以为 `{}`，或包含 `seed`（默认 42）与 `use_demo`（省略时自动选择背景）。创建与七天运行在同一事务中完成。返回包含 `events`、`summary`、`metrics` 的完整分支。重复请求会产生新的独立分支。

自主策略逐日计算候选得分，只使用决策前状态：工作分为 `min(100-进度, 行动基础进度)/19 × 30 × (1+已过天数/14)`；作息/精力分为 `实际精力变化×0.65 - 睡眠目标缺口×6 - 行动后精力低于45的缺口×1.2`；自由时间分为 `自由小时×0.8`。选择总分最高的行动；并列时按全力推进、协商、休息的固定顺序。先按未舍入分数组合、保留两位小数后比较。这是公开的游戏权重，不是概率或医学模型；当天尚未发生的外部事件不参与选择。

每日记录保留候选评分与选择理由，可在“查看 / 分岔”中查看。固定种子和档案快照可重放结果，模拟经历不会写回真实记忆。

### 基础行动规则

每天严格分配 24 小时，其中日常生活固定 3 小时，剩余未占用时间计入自由时间：

| 行动 | 工作 | 睡眠 | 运动 | 项目基础进度 | 精力变化 |
| --- | --- | --- | --- | --- | --- |
| 全力推进 | 11h | 6.5h | 0h | +19 | -13 |
| 协商范围 | 8h | 8h | 0.5h | +12 | -2 |
| 减少工作 | 5h | 8.5h | 1h | +6 | +9 |

每日外部事件带来 +3、-2 或 0 项目进度，以 SHA-256(seed:day) 确定。进度与精力限制在 0–100，起始精力 65、进度 0。项目进度只是抽象指标，达到 100 后仍可能因后续需求变化而下降。

- 平衡策略：精力低于 45 时减少工作，否则协商推进。
- 事业策略：精力至少 25 且进度不足 100 时全力推进，否则协商。
- 休息策略：精力不足 85 时减少工作，否则协商。

所有参数是公开的游戏假设。精力不是身体指标，项目进度不是晋升概率；结果不是现实预测或医疗建议。两个顾问为独立规则角色，鲍勃依据当前策略行动。首版没有接入 LLM、自由文本行动、真实日历、收入模型或长期学习。自由文本人物目标用作背景，不被偷偷转成优化函数。

比较时仅展示相同档案、记忆和种子的分支，并显示各自推进天数；建议完成七天后比较。手动行动保存在事件中，导出包含引擎版本、种子、快照和逐日状态，可重放。并发推进采用 `expected_day` 防止旧页面重复写入。

## 验证

安装测试依赖（当前云实例已预装 httpx）：

```sh
python -m pip install -r requirements-dev.txt
python -m unittest discover -s tests -v
```

测试使用临时数据库，不触碰用户记录，覆盖完整七天流程、24 小时守恒、重放、分岔、共同事件、记忆隔离与删除、快照、持久化、无效输入和跨来源写入。

如已安装 Playwright 与 Chromium，可用 `python tests/browser_smoke.py` 运行真实浏览器流程验证。该脚本启动临时 8765 端口服务、使用独立临时数据库，结束时关闭服务。覆盖手动/自主推进、回到选择分岔、无效 JSON、导入与文本转义、批量对比、导出、刷新持久化、删除和手机布局。截图保存在 `/tmp/bob-world-*.png`。

## 目录与后续扩展

```text
backend/app.py       FastAPI、SQLite、记忆与分支接口
backend/engine.py    确定性世界、顾问规则与策略
web/app.jsx         React 前端
web/build/          esbuild 生成的浏览器资源（不入库）
tests/              核心行为测试
```

首版采用 React + FastAPI + SQLite，构建工具为 esbuild。前端只依赖 `/api/*` JSON 接口。下一步可加入经用户选择的 GLM/DeepSeek 教练服务、自由行动的结构化校验、更丰富的世界规则和 PostgreSQL。云端教练接入时应明确选择发送哪些记忆，保留规则计算与叙事解释的边界。

当前为本地单用户工具，没有登录、用户隔离和生产部署配置。默认绑定回环地址；开放给其他用户前需要增加认证、访问控制和 HTTPS。数据库含导入原文，保存在本地，未做应用层加密。备份时需一并保护。
